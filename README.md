## Descripción

Proyecto correspondiente al **Taller 1**, basado en una solución de arquitectura mediante microservicios.

Hasta el momento se ha trabajado en el diseño de la **API Festivos**, utilizando **Express JS y MongoDB**, junto con el modelado de la base de datos de festivos y la elaboración de los diagramas **objetual y de arquitectura**.

La API contempla operaciones de **CRUD de festivos, verificación de fechas festivas y listado de festivos por año**, incluyendo el cálculo de fechas festivas según las reglas establecidas en el taller.
